# Sachin Agarwal - Personal Portfolio

Production-grade personal portfolio website for **Sachin Agarwal** (Product Management & AI SaaS Strategy · Ex-Indus Insights · IIT Kharagpur '24 · Ex-AiDash).

## Features

- **Recruiter Perspective Switcher**: Dynamic view filtering across Product Management, Strategy & Operations, Engineering & ML, and Comprehensive profile.
- **AiDash AI Unit Economics Simulator**: Real-time calculator showcasing model routing policy, token cost reductions, and contract runway forecasting.
- **Roll to Goal 3D Physics Game**: In-browser playable marble arcade game celebrating Sachin's self-built Unity Android game (900+ downloads, 4.9★ rating on Google Play).
- **Google Drive Integration (OAuth v3)**: Secure read-only access to browse and inspect documents from Google Drive.
- **Pre-Verified Credentials Vault**: 12 verified citations and proof documents including Mathematics Olympiad trophy, Indian Case Challenge 2022 (top IIT team), IIT Kharagpur transcripts, and leadership appointments.
- **Resume Hub**: Instant access to 4 specialized resumes (Product Management, Strategy & Ops, Shiprocket APM, Comprehensive).

## Tech Stack

- **Framework**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4
- **Animations & Icons**: Lucide React, Motion
- **Integrations**: Firebase Auth, Google Drive API v3

## Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
